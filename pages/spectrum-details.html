How this form works & what gets computed
  • Basic Details. Licensee Name and Financial Year. They drive the heading of Table 1, the print header and the default quarter dates.
  • Spectrum Types. Tick the spectrum types available. Ticking GSM MWA, GSM MWB, E-Band or Other adds a dedicated row-block for that type inside the Backbone Spectrum table — each block has its own Quarter / From / To / SUC Rate / Weighted Average rows.
  • Spectrum Holdings of M/s … One row per allotment. Sl No is generated automatically. Technology is a right-aligned drop-down. All values are vertically centred. Near-expiry rows are shaded orange in the Effective Date column.
  • A. SUC Rate for GSM Access Spectrum. Populated automatically from Table 1 — only GSM Access / GSM Access (3G) / GSM Access (BWA) rows appear. “Quantum of Spectrum from 16.08.2016” is 2 × Quantum when the Frequency Band is 2100 MHz or below (bands above 2100 MHz keep the same quantum).
  • B. Weighted Average of SUC Rate for the Quarter. The SUC Rate cell for each period is auto-computed as ROUNDUP(Σ(Quantum2016 × Qn) / Σ(Quantum2016), 4) — only counting spectrum rows whose Spectrum Effective Date ≤ period To AND Spectrum Expiry Date ≥ period From. The Weighted Average cell is Σ(SUC Rate × days) / Σ(days).
  • II. Calculation of SUC Rate for GSM MWA/MWB Spectrum. Contains A. SUC Rate for Backbone Spectrum — each ticked backbone spectrum type gets its own row-block. The Weighted Average cell is auto-computed as Σ(rate × days) / Σ(days).
  • III. Summary of SUC Rate Calculation. Fully derived — the MAIN column mirrors the “Weighted Average” of the GSM Access quarterly table, and each backbone column mirrors the corresponding type’s “Weighted Average”. Values are rounded to 4 decimals, shown with a minimum of 2 decimals and a trailing % (e.g. 5.00 %).
  • Remarks. A free-form text area — appears verbatim in the print sheet.
  • Paste from Excel. Copy a rectangular block from Excel and paste into the first cell of any table.
  • Print / PDF. Builds a black-and-white print-only sheet and opens the browser print dialog.
  • Persistence. Everything is remembered in your browser. RESET ALL wipes the saved cache and returns a blank form.
All values are stored exactly as typed. Calculations use full precision internally.
